## 2. Rejection Analysis & Defect Categories

### 2.1 Validation Leakage Interception (312 Documents Purged)
- **Quality Web (`fineweb-edu`)**: 120 collisions.
- **Educational (`cosmopedia-v2`)**: 95 collisions.
- **Source Code (`codeparrot-clean`)**: 97 collisions.
- *Root Cause*: Because the newly acquired web, educational, and code streams share upstream roots with the historical 100M/250M datasets, early rows in the Hugging Face dataset mirrors overlapped with our frozen validation set (`val_documents.jsonl`).
- *Impact*: The pre-generation quarantine hash filter intercepted and purged all 312 collisions, achieving **0.00% validation contamination**.

### 2.2 Quality Heuristic Attrition (782 Documents Purged)
- **Source Code (552 purges)**: Code files with high autogenerated boilerplate, minified single-line scripts, or low alphanumeric ratios ($<0.40$).
- **Mathematics (132 purges)**: Non-English LaTeX fragments or web scrapes lacking substantive mathematical exposition.
- **Dialogue (76 purges)**: Conversations with single-word replies or degenerate repetition loops.
- **Wikipedia (9 purges)**: Disambiguation pages and stub redirect articles.
